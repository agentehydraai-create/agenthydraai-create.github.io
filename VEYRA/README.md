# VEYRA — Portfólio

Portfólio estático de desenvolvimento web para a marca VEYRA, feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `css/style.css` — identidade visual, layout responsivo e animações.
- `js/main.js` — menu mobile, ano automático e animações de entrada.
- `assets/` — pasta reservada para imagens e outros recursos locais.

## Executar localmente

1. Extraia a pasta.
2. Abra `index.html` no navegador, ou abra a pasta no VS Code e use uma extensão como Live Server.
3. Confira os links antes de publicar.

Não há etapa de build nem dependências JavaScript para instalar. A fonte do Google é externa; se preferir funcionamento totalmente offline, remova o link de Google Fonts no HTML e use fontes do sistema.

## Antes de publicar

1. No `index.html`, substitua `https://github.com/` pelo endereço real do seu perfil GitHub nos dois links correspondentes.
2. Confira se o Instagram `@veyra.dev` é o perfil que deseja divulgar.
3. Atualize descrição, serviços e textos conforme os serviços que realmente oferece.
4. Teste no celular e no computador.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha a publicação pela branch principal e pela pasta `/ (root)`.
5. Salve e aguarde o GitHub informar a URL publicada.

O site não possui backend, banco de dados, formulário que envia mensagens ou processamento de pagamentos. O contato é feito pelos links externos exibidos na página.
